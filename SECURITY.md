# Security Policy

## Supported Versions

Only the latest release of **Any Converter** is actively supported with security updates. We encourage all users to upgrade to the latest version to receive bug fixes and security patches.

| Version | Supported |
| :--- | :--- |
| 1.x.x |  Yes |
| < 1.0.0 |  No |

## Reporting a Vulnerability

If you discover a security vulnerability in Any Converter, please **do not open a public issue**. Instead, report it privately to our security team.

### How to Report
- Send a detailed email to **security@swiftgrab.com**.
- Include a description of the vulnerability, instructions or a proof-of-concept (PoC) to reproduce the issue, and the impact of the exploit.
- We will acknowledge receipt of your report within 48 hours and work with you to coordinate a release schedule for the patch.

### Our Commitment
- We will investigate and address reported vulnerabilities in a timely manner.
- We will credit you for your discovery in the release notes unless you request to remain anonymous.
- We practice responsible disclosure and ask that you give us a reasonable timeframe to patch the issue before making it public.
